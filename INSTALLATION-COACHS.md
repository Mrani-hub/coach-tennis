# Message d'installation à envoyer aux coachs

Remplacez les deux liens par les vôtres avant l'envoi.

---

Bonjour,

Voici l'application **Coach USCM** pour planifier et suivre les entraînements de vos jeunes joueurs. Elle est gratuite, ne demande pas de compte et vos données restent sur votre téléphone.

**📱 Sur Android**
1. Ouvrez ce lien sur votre téléphone : LIEN_APK
   (ou ouvrez le fichier CoachUSCM.apk reçu dans WhatsApp)
2. Touchez **Installer**. Si le téléphone le demande, autorisez l'installation depuis cette source (Chrome, WhatsApp ou Fichiers).
3. Si Google Play Protect affiche un avertissement, touchez **Plus de détails → Installer quand même** : l'appli ne vient simplement pas du Play Store.
4. Dans l'appli, **Réglages → Rappels de séances** pour être prévenu avant chaque entraînement.

**🍏 Sur iPhone**
1. Ouvrez ce lien **avec Safari** : LIEN_IPHONE
2. Touchez le bouton **Partager** (carré avec une flèche vers le haut), puis **Sur l'écran d'accueil**, puis **Ajouter**.
3. Ouvrez Coach USCM depuis l'icône de l'écran d'accueil. L'appli fonctionne ensuite sans connexion.

**Pour bien démarrer**
- L'appli s'ouvre avec des données d'exemple. Quand vous êtes prêt : **Réglages → Vider toutes les données**, puis indiquez votre prénom, vos disponibilités et ajoutez vos joueurs.
- Pensez à faire de temps en temps **Réglages → Exporter un fichier de sauvegarde**. Ce fichier sert aussi à passer vos données sur un nouveau téléphone.

**Mises à jour**
- Android : installez simplement le nouveau fichier reçu, vos données sont conservées.
- iPhone : la mise à jour se fait toute seule à l'ouverture.

Vos idées pour améliorer l'appli sont les bienvenues : répondez à ce message.
